# 🍔 Food Delivery Platform

A full-stack MERN Food Delivery Platform developed as part of my Web Development Internship at Infotact Solutions.

The platform enables customers to browse restaurants, order food, manage their cart, and track orders. It also includes separate dashboards for Restaurant Partners and Delivery Partners to demonstrate a multi-role food delivery system.

---

## 🚀 Features

### 👤 Customer Module

- User Login
- Browse Restaurants
- View Restaurant Menus
- Add Items to Cart
- Increase / Decrease Quantity
- Remove Items from Cart
- Checkout
- Place Orders
- View Order History
- Logout

### 🍽 Restaurant Partner Module

- Restaurant Dashboard
- View Menu Items
- View Customer Orders
- Dashboard Statistics
  - Total Orders
  - Revenue
  - Menu Items
  - Pending Orders

### 🛵 Delivery Partner Module

- Delivery Dashboard
- View Assigned Orders
- View Delivery Address
- View Order Status

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/food-delivery-platform.git
```

### Install Dependencies

Frontend

```bash
cd client
npm install
npm run dev
```

Backend

```bash
cd server
npm install
npm run dev
```
